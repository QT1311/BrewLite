# BrewLite v1.0.0

Bản phát hành đầu tiên của BrewLite, ứng dụng đặt và thanh toán đồ uống không dùng tiền mặt.

- **Production (web):** https://web-production-97f35c81.up.railway.app
- **Production (API):** https://api-production-9d99f943.up.railway.app/health
- **Image:** `ghcr.io/qt1311/brewlite-api:v1.0.0`, `ghcr.io/qt1311/brewlite-web:v1.0.0`

## Tính năng
- Xem menu, chi tiết món, chọn size/topping, giá cập nhật theo lựa chọn (FR-01 đến FR-03).
- Giỏ hàng: thêm, sửa số lượng, xoá, tự tính tổng (FR-04 đến FR-06).
- Đăng ký, đăng nhập JWT, mật khẩu băm bcrypt (FR-07 đến FR-09, NFR-02, NFR-05).
- Đặt đơn: server tự tính giá, giữ tồn kho khi nhiều khách đặt đồng thời (FR-10, FR-17).
- Thanh toán mock có Idempotency-Key, xử lý thanh toán lỗi và thử lại (FR-11 đến FR-13).
- Xác nhận đơn, theo dõi trạng thái, lịch sử đơn (FR-14, FR-15); máy trạng thái đơn hợp lệ (FR-16).
- API nhân viên quầy cập nhật `PREPARING → READY → COMPLETED` bằng `x-staff-key`.

## Hạ tầng và quy trình
- Migration TypeORM thay `synchronize` (ADR 008); migration chạy khi API khởi động.
- Dockerfile cho web và api, Docker Compose chạy đủ web + api + db bằng một lệnh.
- CI: lint, typecheck, test, build, E2E Playwright trên Docker Compose; chặn merge khi đỏ.
- CD: push `main` hoặc tag `vX.Y.Z` → CI → build image → GHCR (tag theo commit SHA) → deploy Railway → smoke test; lỗi thì tự rollback (ADR 009).
- Rollback thủ công bằng workflow **Rollback** (nhập SHA hoặc tag).
- `/health` trả `version` là commit SHA đang chạy.

## Thay đổi so với bản đầu
- Không có phiên bản trước; đây là bản 1.0.0.

## Hạn chế đã biết
- Thanh toán là mock, chưa kết nối cổng thanh toán thật.
- Chưa có giao diện cho nhân viên quầy (chỉ có API).
- Mã khuyến mãi và điểm thưởng (FR-18, mức Could) chưa làm.
- Redeploy có gián đoạn ngắn (không blue/green).

## Nâng cấp / rollback
- Nâng cấp: merge vào `main` hoặc đẩy tag mới, pipeline tự deploy.
- Rollback: Actions → Rollback → nhập SHA hoặc tag trước đó. Chi tiết trong `docs/deployment.md`.
